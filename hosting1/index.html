Berapa biaya pendidikan di PeTIK II Jombang?

Program pendidikan di PeTIK ditujukan untuk para pemuda berprestasi dan dhuafa/mustahik melalui program beasiswa penuh (asrama, makan, dan pelatihan komputer gratis).

Berapa lama masa studi di PeTIK II?

Program intensif berlangsung selama 1 tahun (2 semester) yang mencakup pembelajaran IT, tahsin Al-Qur'an, sertifikasi, dan program magang kerja di industri.
